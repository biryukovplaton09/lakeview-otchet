# Открытый отчёт Lakeview

Сайт «Открытый отчёт» Платона Бирюкова, кандидата в Президенты ученического самоуправления Lakeview School Almaty.

- `index.html`, `style.css`, `app.js` — страница.
- `data.json` — всё содержимое отчёта: статусы инициатив, голосование «Решаем за 30 дней», идеи учеников с ответами и отчёты по четвертям. Чтобы обновить сайт, достаточно поменять этот файл.

Сообщения от учеников приходят через встроенную Google Форму.
